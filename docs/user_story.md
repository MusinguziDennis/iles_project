## Student Intern
- As a student intern, I want to register for an account so that I can access the system.
- As a student intern, I want to log in securely so that my data is protected.
- As a student intern, I want to view my internship placement details so that I can confirm my company, workplace supervisor, and academic supervisor.
- As a student intern, I want to create a weekly log entry so that I can document my activities.
- As a student intern, I want to save a weekly log as a draft so that I can complete it later.
- As a student intern, I want to submit a weekly log for review so that my supervisors can evaluate my progress.
- As a student intern, I want to edit my submitted log if it is not yet approved so that I can correct mistakes.
- As a student intern, I want to see the status of my logs (draft, submitted, reviewed, approved) so that I know what action is needed.
- As a student intern, I want to receive feedback from my workplace supervisor and academic supervisor so that I can improve my performance.
- As a student intern, I want to view a history of all my weekly logs so that I can track my progress over the internship period.

## Workplace Supervisor
- As a workplace supervisor, I want to log in to the system so that I can access the logs of interns assigned to me.
- As a workplace supervisor, I want to view a list of student interns under my supervision so that I can manage their logs.
- As a workplace supervisor, I want to open a student’s weekly log so that I can read their submitted entries.
- As a workplace supervisor, I want to mark a log as “reviewed” after reading it so that I indicate I have seen it.
- As a workplace supervisor, I want to approve a log so that the student knows their entry is accepted from the workplace side.
- As a workplace supervisor, I want to request changes to a log with comments so that the student can revise it.
- As a workplace supervisor, I want to add feedback to a log so that I can guide the student.
- As a workplace supervisor, I want to filter logs by status (submitted, reviewed, approved) so that I can prioritise my work.

## Academic Supervisor
- As an academic supervisor, I want to log in to the system so that I can access the logs of students I supervise.
- As an academic supervisor, I want to view a list of students assigned to me so that I can oversee their progress.
- As an academic supervisor, I want to open a student’s weekly log so that I can review their entries.
- As an academic supervisor, I want to see the workplace supervisor’s feedback and approval status so that I have a complete view.
- As an academic supervisor, I want to add my own feedback to a log so that I can provide academic guidance.
- As an academic supervisor, I want to mark a log as “approved” after confirming that both workplace requirements and academic expectations are met.
- As an academic supervisor, I want to generate a final report for a student at the end of the internship so that I can assign a grade.

## Administrator / Coordinator
- As an administrator, I want to create and manage user accounts so that only authorised people access the system.
- As an administrator, I want to assign workplace supervisors and academic supervisors to students so that each student has the correct oversight.
- As an administrator, I want to create internship placement records so that students are linked to their company, workplace supervisor, and academic supervisor.
- As an administrator, I want to view all logs and placements in the system so that I can monitor overall progress.
- As an administrator, I want to generate reports (e.g., number of logs per student, approval rates per supervisor) so that I can evaluate the internship programme.
- As an administrator, I want to reset passwords and manage user roles so that security is maintained.
